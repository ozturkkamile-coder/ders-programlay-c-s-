
# 📚 Ders Programlayıcısı

## 📌 Proje Hakkında
Ders Programlayıcısı, öğrencilerin haftalık ders programlarını kolayca oluşturabilmeleri ve düzenleyebilmeleri için geliştirilmiş bir web uygulamasıdır.

Bu uygulama sayesinde kullanıcılar ders adı, gün, başlangıç ve bitiş saatlerini girerek kendi haftalık ders programlarını oluşturabilir.

## ✨ Özellikler
- Ders ekleme ve silme
- Eklenen dersleri düzenleme
- Dersleri başlangıç saatine göre sıralama
- Günlere göre ders filtreleme
- Derslere farklı renkler verme
- Çakışan dersleri engelleme
- Haftalık ders sayısını görüntüleme
- LocalStorage ile verileri kaydetme
- Ders programını yazdırma ve PDF olarak kaydetme

## 🛠️ Kullanılan Teknolojiler
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- LocalStorage

## 🚀 Nasıl Kullanılır?
1. Ders adını girin.
2. Dersin yapılacağı günü seçin.
3. Başlangıç ve bitiş saatlerini belirleyin.
4. Ders Ekle butonuna tıklayın.
5. Oluşturduğunuz ders programını görüntüleyin ve gerektiğinde düzenleyin.

## 🎯 Projenin Amacı
Bu projenin amacı, JavaScript ve web geliştirme konularında öğrenilen bilgileri uygulamaya dökmek ve öğrencilerin ders programlarını daha düzenli bir şekilde yönetmelerini sağlamaktır.
